# Character Cut (Рез персонажа) v0.2

Blender add-on: разрезание персонажей на печатные детали со штифтом/гнездом.

- Панель N → **Рез персонажа** (русский UI + иконки)
- **Прямой рез** и **Кривой рез (нарисовать)** — полилиния на поверхности
- Локальный пояс реза: петля вокруг руки/ноги не режет весь персонаж
- Черновик / Быстрый режим
- Пресеты: Голова, Пояс, Руки, Ноги
- Экспорт STL / OBJ / FBX

Установка: Edit → Preferences → Add-ons → Install from Disk → ZIP.

Кривой рез: ЛКМ — точка, Backspace — назад, C — замкнуть, Enter/ПКМ — ОК, Esc — отмена.
Стрелку коннектора направьте вдоль отделяемой конечности.

Требования: Blender 4.2+, закрытая manifold-сетка, сцена в мм, Apply Scale/Rotation.
