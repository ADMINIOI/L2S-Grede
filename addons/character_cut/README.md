# Character Cut (Рез персонажа) v0.2.1

Blender add-on: разрезание персонажей на печатные детали со штифтом/гнездом.

## Как пользоваться (как CatPin)

1. Выберите персонажа в viewport  
2. N → **Рез персонажа** → **Кривой рез (нарисовать)** или **Прямой рез**  
3. Кликайте точки прямо по модели — без «взять источник» и без обязательной конвертации mesh  

- Русский UI + иконки  
- Локальный кривой рез (петля вокруг руки/ноги)  
- Черновик / Быстрый режим  
- Экспорт STL / OBJ / FBX  

Manifold-проверка — только предупреждение, рисование не блокирует.

Установка: Edit → Preferences → Add-ons → Install from Disk → ZIP.  
Blender 4.2+.
