# AXISBOX

Blender add-on: разрезание персонажа линией/пером и соединение ключом/штифтом.

- N-панель → вкладка **AXISBOX**
- Русский интерфейс
- Формы: ласточкин хвост, шар, цилиндр, коробка, шестигранник, конус, крест, Т-шип
- Перо по поверхности, несколько резов, утопленный шов, разнос деталей

Установка: Edit → Preferences → Add-ons → Install from Disk → `axisbox-addon.zip`.

Blender 4.2+ / 5.0+.
